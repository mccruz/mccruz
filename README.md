## How I approach delivery

- Explain the business problem and show the intended output first.
- Use fixed rules where a decision should be repeatable and inspectable.
- Test missing data, duplicates, interruptions, and recovery paths.
- Make limitations and the human decision point visible.

The repositories contain Python, JavaScript, SQL, n8n, and Docker work. Their
READMEs link to the key implementation files and checks, so technical reviewers
can follow the evidence without reading every file.
